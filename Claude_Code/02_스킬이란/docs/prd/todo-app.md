# PRD: Todo 앱 (Django + Vue)

## 배경 및 목적
할 일을 추가, 수정, 삭제, 완료 처리하고 마감일과 카테고리로 관리할 수 있는 개인용 Todo 웹 앱을 만든다. 로그인 없이 바로 사용 가능한 단일 사용자 도구로, Django(백엔드 API)와 Vue(프론트엔드)를 학습/실습 목적으로 함께 사용한다.

## 대상 사용자
로그인 없이 혼자 사용하는 단일 사용자 (본인 전용 할 일 관리)

## 아키텍처
- **백엔드**: Django + Django REST Framework — Todo 모델에 대한 REST API 제공
- **프론트엔드**: Vue 3 (Vite) — API를 호출해 목록을 렌더링하고 조작하는 SPA
- **DB**: SQLite (개발용 기본값)
- CORS는 Vue 개발 서버(`localhost:5173` 등)에서 Django API(`localhost:8000`)를 호출할 수 있도록 설정

## 핵심 시나리오
1. 사용자가 앱을 열면 등록된 할 일 목록이 보인다.
2. 할 일 제목(+선택적으로 마감일, 카테고리)을 입력해 새 항목을 추가한다.
3. 목록에서 체크박스를 눌러 완료/미완료 상태를 토글한다.
4. 항목을 클릭/편집 버튼으로 내용·마감일·카테고리를 수정한다.
5. 항목을 삭제한다.
6. 카테고리(태그)로 목록을 필터링해서 본다.

## 요구사항
- Todo 모델 필드: 제목(title), 완료 여부(done), 마감일(due_date, 선택), 카테고리(category, 선택), 생성일시
- REST API: 목록 조회(GET), 생성(POST), 수정(PUT/PATCH), 삭제(DELETE) — `/api/todos/`
- Vue 화면: 할 일 목록, 추가 폼, 수정 UI, 완료 토글, 삭제 버튼, 카테고리 필터
- 마감일이 지난(overdue) 항목은 목록에서 시각적으로 구분 표시 (예: 빨간색 텍스트)

## 입력 / 출력
- 입력: 할 일 제목(필수), 마감일(선택, 날짜), 카테고리(선택, 텍스트/드롭다운)
- 출력: 할 일 목록(JSON API 응답 → Vue에서 렌더링), 완료 상태, 카테고리별 필터링 결과

## 예외 처리
- 제목이 비어 있으면 추가 버튼 비활성화 또는 에러 메시지 표시
- 존재하지 않는 항목 수정/삭제 시도 시 API가 404 반환, 프론트에서 에러 안내
- API 서버가 응답하지 않을 경우 프론트에 "불러오기 실패" 메시지 표시

## 성공 기준
- 할 일을 추가/수정/삭제/완료 처리할 수 있고, 새로고침 후에도 DB에 데이터가 유지됨
- 마감일 설정 및 지난 마감일 표시가 동작함
- 카테고리로 필터링이 동작함

## 범위 제외 (Out of scope)
- 로그인/회원가입, 다중 사용자 지원
- 알림(푸시/이메일) 기능
- 배포(프로덕션 서버, HTTPS 등) 설정 — 로컬 개발 환경 기준으로만 진행

## 제약 조건 / 참고사항
- 기존 코드베이스 없음 (신규 프로젝트) — Django 프로젝트와 Vue 프로젝트를 하나의 저장소 안에 `backend/`, `frontend/` 형태로 분리해서 구성할 예정
