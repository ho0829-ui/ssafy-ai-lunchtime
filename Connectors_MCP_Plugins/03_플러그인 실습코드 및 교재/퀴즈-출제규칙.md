# 퀴즈 메이커 — 출제 규칙과 출력 형식

## 출제 규칙

1. 제공된 학습 자료 안에서만 출제한다. 자료 밖 지식으로 보충하지 않는다.
2. 객관식은 보기 4개, 정답 1개로 만든다.
3. 문제지와 정답지를 분리한다. 문제지에는 정답·해설·근거를 쓰지 않는다.
4. 정답마다 해설, 파일명, 문단 식별자, 원문 근거 문장을 붙인다.
5. 근거가 부족하면 억지로 채우지 않고, 부족한 문항 수와 이유를 알린다.

## 기본값

사용자가 지정하지 않으면 아래를 적용하고 결과에 명시한다.

- 5문항 — 객관식 3, 참/거짓 2
- 난이도 중

## 출력 형식

두 파일로 나눠 저장한다.

### questions.md

```markdown
# [제목] 문제지

## Q01 객관식
[문제 문장]
  ① [보기]   ② [보기]
  ③ [보기]   ④ [보기]

## Q02 참/거짓
[진술 문장]   ( O / X )
```

### answers.md

```markdown
# [제목] 정답지

## Q01
정답: ②
해설: [한 문장]
원문 위치: [파일명] / [M0x]
근거 문장: "[원문에서 그대로 복사]"
```

## 근거 규칙

- `근거 문장`은 원문에서 **글자 그대로** 복사한다. 의역·생략 금지.
- 그 문장만 읽고도 정답이 확정되어야 한다. 주제만 같은 문장은 근거가 아니다.
- `[M0x]`는 학습 자료의 문단 식별자다. 자료에 없으면 문단 번호를 매겨 표기한다.

## 금지

- 원문 파일을 수정하지 않는다.
- 자료 밖 지식을 보충하지 않는다.
- 근거를 지어내지 않는다.
- 부족한 문항을 억지로 채우지 않는다.

## 제약

- Python 스크립트 없이, 마크다운 파일만으로 동작하게 한다.
