# Git 기초 · 출제용 자료 문제지

## Q01 객관식
작업 트리와 스테이징 영역의 상태를 확인할 때 사용하는 명령은?
  ① git add   ② git stash
  ③ git status   ④ git commit

## Q02 객관식
스테이징된 내용을 새 커밋으로 기록하는 명령은?
  ① git commit   ② git status
  ③ git add   ④ git stash

## Q03 객관식
커밋하기 애매한 변경사항을 잠시 치워 두고 싶을 때 사용하는 명령은?
  ① git status   ② git commit
  ③ git add   ④ git stash

## Q04 참/거짓
git add를 실행한 뒤 파일을 다시 수정했다면, git add를 다시 실행하지 않아도 새 수정 내용이 다음 커밋에 포함된다.   ( O / X )

## Q05 참/거짓
Git은 리눅스 커널을 관리하기 위해 만들어졌다.   ( O / X )
