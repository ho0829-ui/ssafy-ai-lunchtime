# Git 기초 · 출제용 자료 정답지

## Q01
정답: ③
해설: 작업 트리와 스테이징 영역의 상태를 확인하는 명령은 git status입니다.
원문 위치: 퀴즈 출제 참고 파일.md / M01
근거 문장: "git status는 작업 트리와 스테이징 영역의 상태를 확인하는 명령임."

## Q02
정답: ①
해설: 스테이징된 내용을 새 커밋으로 기록하는 명령은 git commit입니다.
원문 위치: 퀴즈 출제 참고 파일.md / M05
근거 문장: "git commit은 스테이징된 내용을 새 커밋으로 기록하는 명령임."

## Q03
정답: ④
해설: 커밋하기 애매한 변경사항을 잠시 치워 둘 때는 git stash를 사용합니다.
원문 위치: 퀴즈 출제 참고 파일.md / M03
근거 문장: "커밋하기 애매한 변경사항을 잠시 치워 두려면 git stash 를 사용한다."

## Q04
정답: X
해설: git add 이후 다시 수정한 내용을 다음 커밋에 넣으려면 git add를 다시 실행해야 합니다.
원문 위치: 퀴즈 출제 참고 파일.md / M06
근거 문장: "git add를 실행한 뒤 파일을 다시 수정했다면, 새 수정 내용도 다음 커밋에 넣기 위해 git add를 다시 실행해야 함."
