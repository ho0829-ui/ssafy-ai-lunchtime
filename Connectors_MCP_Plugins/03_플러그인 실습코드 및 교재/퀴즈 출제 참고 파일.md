# Git 기초 · 출제용 자료

[M01]
git status는 작업 트리와 스테이징 영역의 상태를 확인하는 명령임.

[M02]
git add는 파일의 현재 내용을 다음 커밋에 포함할 수 있도록 스테이징 영역에 추가하는 명령임.

[M03]
커밋하기 애매한 변경사항을 잠시 치워 두려면 git stash 를 사용한다.

[M04]
Git은 2005년 리누스 토르발스가 리눅스 커널을 관리하려고 만들었다.

[M05]
git commit은 스테이징된 내용을 새 커밋으로 기록하는 명령임.

[M06]
git add를 실행한 뒤 파일을 다시 수정했다면, 새 수정 내용도 다음 커밋에 넣기 위해 git add를 다시 실행해야 함.
