# quiz-maker

학습 자료로 퀴즈를 만들어 **문제지**와 **정답지**를 별도 Markdown 파일로 내보냅니다.

## 사용
```
/make-quiz 강의노트.docx 15문항 객관식10 단답5 난이도 상
```
또는 자료를 첨부하고 "이걸로 퀴즈 만들어줘". 지정하지 않으면 10문항(객관식 7 · 단답형 3), 난이도 중.

## 입력 / 출력
- 입력: `.docx`, `.md`, `.txt` (여러 파일 가능)
- 출력: `<제목>_문제지.md`, `<제목>_정답지.md`
  - 문제지: 문항·선택지·답란만
  - 정답지: 빠른 정답표 + 문항별 정답·해설·근거
  - 근거 형식: `📌 근거 — 파일 › 섹션 경로 › 위치` + 원문 인용
    - 위치: md·txt는 `40-42행`, docx는 `12번째 문단` 또는 `표1 3행`

## 근거 보증 방식
1. `extract_source.py`가 자료를 문단 단위로 번호(P1, P2…)를 매겨 색인
2. Claude가 문항과 근거(문단 번호 + 원문 인용)를 `quiz.json`으로 작성
3. `build_quiz.py`가 모든 인용이 해당 문단 원문과 글자 그대로 일치하는지 검사 — 하나라도 어긋나면 파일을 만들지 않음

## 요구 사항
Python 3.8+ (외부 라이브러리 불필요)
