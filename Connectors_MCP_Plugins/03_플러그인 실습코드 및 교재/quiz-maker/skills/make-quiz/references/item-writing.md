# 문항 작성 규칙

## 공통
- 한 문항은 개념 하나만 묻는다. 자료의 사소한 수치·고유명사 암기보다 핵심 개념 이해를 우선한다.
- 난이도 배분(기본 "중"): 개념 확인 40% / 적용·비교 40% / 코드·사례 해석 20%. "하"는 개념 확인 위주, "상"은 적용·해석 위주.
- 부정형 발문("옳지 않은 것은?")은 전체의 30% 이하, 사용 시 **옳지 않은** 처럼 굵게 표시.
- 문항끼리 서로의 정답을 알려주지 않게 한다.
- 문체: "~은?", "~을 쓰시오." 형태의 평가 문체.

## 객관식
- 선택지 길이·문법 형태를 비슷하게 맞춘다(정답만 길거나 구체적이면 안 됨).
- 오답은 자료에 등장하는 인접 개념이나 흔한 오개념으로 만든다. 명백히 무관한 오답 금지.
- "모두 정답", "정답 없음" 선택지는 쓰지 않는다.
- 정답이 하나뿐인지 확인한다. 부분적으로 옳은 선택지가 있으면 발문을 좁힌다.
- 정답 번호를 문항 전체에 고르게 분산한다.

## 단답형
- 답이 한두 단어·숫자·짧은 코드 조각으로 확정되게 묻는다. 서술이 필요한 질문은 객관식으로 바꾼다.
- 표기 변형(대소문자, 괄호 유무, 한/영 표기)은 `accept`에 넣는다.
- 정답 단어가 발문에 그대로 나오지 않게 한다.

## 근거
- 근거 인용만 읽고도 정답이 확정되어야 한다.
- 정답 판단에 두 문단이 필요하면 evidence를 2개 넣는다.
- 인용은 필요한 최소 구간(보통 1~2문장). 문단 전체 복사는 피한다.
